dpx_tc002 firmware — browser install

Flash the Ulanzi TC001 LED matrix firmware directly from this page over USB — no PlatformIO, no drivers, no serial terminal.

Requires desktop Chrome or Edge (Web Serial API). Safari, Firefox, and mobile browsers can't do this — use the PlatformIO CLI instead on those.
  1. Plug the device into this computer via USB.
  2. Click the button below and select the correct serial port when prompted.
  3. If this is a factory-fresh or non-WLED device, choose "erase device" when offered — a device already running this firmware doesn't need it.

Firmware: dubpixel/dpx_tc002_frm — rebuilt automatically from main.
