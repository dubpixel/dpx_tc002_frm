Flash your matrix from the browser

Install the Ulanzi TC001 firmware directly over USB — no PlatformIO, no drivers, no serial terminal. Just this page.

Before you start

⚠️ Requires desktop Chrome or Edge (Web Serial API). Safari, Firefox, and mobile browsers can't do this — use the PlatformIO CLI instead on those.
  1. Plug the device into this computer via USB.
  2. Click Connect below and select the correct serial port when prompted.
  3. If this is a factory-fresh or non-WLED device, choose erase device when offered — a device already running this firmware doesn't need it.
