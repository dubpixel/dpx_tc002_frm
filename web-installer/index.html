dpx_tc002_frm

WLED for your wrist-worn pixel clock

Flash it from a browser, drive it from OSC/MQTT/HTTP.

dpx_tc002_frm turns the Ulanzi TC001 into a networked 32×8 status display — notifications, timecode, custom clocks, and 200+ WLED effects, all controllable without touching a soldering iron. Built on WLED plus the original dpx_matrix usermod.

Flash a device →

What it adds over stock WLED

  • Text app loop — scrolling/static custom apps, clocks, WLED pattern slots
  • Notifications — one-shot priority messages, with a recall/history backlog
  • Timecode display (LTC via OSC) with frame progress bar
  • Pixel overlay effects — weather, decorative, full-screen — composited on top of any WLED effect
  • OSC + MQTT + HTTP control, all first-class
  • Browser-flashable — no PlatformIO needed, see above
